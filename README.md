## 🌟 Feature Highlights (v5.1.4)

### 1. 🚀 Fixed Channel Scrolling & Hardware Acceleration
- **Smooth 60fps Scrolling**: Fixed CSS rule boundary so the channel catalog scrolls smoothly with trackpad two-finger gestures, mouse wheel, or scrollbar dragging across all 2,989 channels.
- **Enhanced Buffer Pre-fetching**: Increased scroll lazy-load buffer threshold to 800px for seamless infinite scroll with zero hitching.
- **Keyboard Navigation**: ArrowUp / ArrowDown and PageUp / PageDown smoothly scroll through channels when browsing.

### 2. 🏟️ Professional Sports Broadcast UI
- **Apple TV+ & ESPN Inspired Card Aesthetic**: High-end frosted glassmorphic cards with precision monospaced scoreboards and subtle colored left accent lines.

### 3. 👁️ 1-Click Show / Hide Information Toggle
- **Compact vs Detailed Mode**: Instantly collapse cards into sleek score strips (teams + score + watch button) or expand into full telemetry with one click.
- **Persistent Preferences**: Remembers your preferred view mode across app restarts using local storage.

### 4. ✕ Live Sports Section Dismiss & Toolbar Toggle
- Dismiss the live events carousel directly with the header `✕` button or toggle it anytime from the top tools bar (`🔥 Sports`).

### 5. ⚡ Prominent Header Update Icon & Status Pill
- Always-visible update badge in `header-left` and 1-click live GitHub version check.

### 6. 🛡️ 100% Ad-Free Experience (Zero-Ad Shield)
- All 2,989 channels stream without commercial interruptions, popup ads, or tracking scripts.
