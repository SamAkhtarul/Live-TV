## 🌟 Feature Highlights (v5.1.3)

### 1. 🏟️ Professional Sports Broadcast UI
- **Broadcasting-Grade Aesthetic**: Re-engineered sports cards with dark frosted glassmorphism, monospaced scoreboards, and subtle accent lines inspired by Apple TV+ and ESPN.
- **Clean Visual Hierarchy**: Replaced cluttered boxes and harsh dashed borders with refined typography and inline live indicators.

### 2. 👁️ 1-Click Show / Hide Information Toggle
- **Compact vs Detailed Mode**: Instantly collapse cards into sleek, space-saving score strips (teams + score + watch button) or expand into full match telemetry with one click.
- **Persistent Preferences**: Remembers your preferred view mode across app restarts using local storage.

### 3. ✕ Live Sports Section Dismiss & Toolbar Toggle
- Dismiss the live events carousel directly with the header `✕` button or toggle it anytime from the top tools bar (`🔥 Sports`).

### 4. ⚡ Prominent Header Update Icon & Status Pill
- Always-visible update badge in `header-left` and 1-click live GitHub version check.

### 5. 🗜️ Ultra-Compact Desktop Header & Scroll-Free Phone Experience
- Zero horizontal overflow across desktop and mobile, with 100% single-screen Phone TV and remote controllers.

### 6. 🛡️ 100% Ad-Free Experience (Zero-Ad Shield)
- All 2,989 channels stream without commercial interruptions, popup ads, or tracking scripts.
